About

Relationship to PARI/GP

LibPARI.jl is an independent, community-maintained Julia interface to the PARI/GP computer algebra system. It is not affiliated with, endorsed by, or maintained by the PARI Group or the PARI/GP development team.

PARI/GP is developed by the PARI Group and distributed under the GNU General Public License. LibPARI only calls into the official PARI library, supplied by PARI_jll, and does not modify it.

Any errors in the Julia interface, the high-level API, or this documentation are the responsibility of LibPARI's maintainers, not of the PARI Group.

Reporting bugs

  • Bugs and feature requests about this Julia wrapper go to LibPARI's issue tracker.
  • Bugs and feature requests about PARI/GP itself go to the official PARI/GP bug tracker or the pari-users mailing list.

Development

The main entry points are recipes in the repository's justfile (run them with just; just alone lists them). Each runs what CI runs:

RecipeWhat it does
just testthe test suite (Pkg.test())
just test-threadsthe multi-threaded concurrency suite
just test-no-trapthe same, without the C trap shim (serial fallback)
just docsthis documentation, llms.txt and llms-full.txt (strict: any warning fails)
just format / just format-checkJuliaFormatter, pinned as in CI
just generateregenerate src/bindings.jl from PARI's pari.desc
just checkformat check, tests, threaded suite and docs

Without just, the underlying commands are plain Julia, e.g.:

julia --project=. -e 'using Pkg; Pkg.test()'
julia --project=docs -e 'using Pkg; Pkg.develop(path = "."); Pkg.instantiate()'
julia --project=docs docs/make.jl

Source code is formatted with JuliaFormatter to an 80-column margin, enforced in CI and by pre-commit.

The project follows Semantic Versioning. Notable changes are recorded in the changelog, and the implementation plan is in ROADMAP.md.
